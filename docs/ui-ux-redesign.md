# Heallu Mobile UI/UX Redesign

작성일: 2026-04-13

## 1. 리디자인 목표

- 앱을 처음 실행한 사용자가 3초 안에 구조를 이해할 수 있게 만든다.
- 핵심 행동을 줄여 한 화면에 하나의 목적만 보이게 한다.
- 현재 분산된 기능을 더 적은 탭과 더 명확한 흐름으로 재배치한다.
- 감성적인 인상은 유지하되, 생산성과 운동 기록의 실용성을 함께 살린다.

## 2. 현재 구조의 문제

현재 하단 탭은 다음처럼 기능이 과하게 분산되어 있다.

- 홈
- 운동
- AI 트레이너
- 진행
- 내 루틴
- 커뮤니티
- 프로필

### 현재 사용성 문제

- 첫 진입 시 "무엇부터 해야 하는지" 바로 이해되지 않는다.
- 탭이 많아 핵심 기능이 서로 경쟁한다.
- AI, 운동, 루틴, 진행이 따로 놀아 학습 비용이 높다.
- 한 화면 안에 설명, 카드, 선택 UI, 타이머, 입력창이 동시에 많아 집중이 흐려진다.
- 버튼과 텍스트가 화면마다 톤이 달라 일관성이 떨어진다.

## 3. 리디자인 방향

핵심 철학:

- Less but better
- 한 화면, 한 행동
- 탭 4개 이하
- 상단은 요약, 중간은 핵심 카드, 하단은 1개의 강한 CTA

디자인 톤:

- Apple, Notion, Toss 계열의 정돈된 플랫 UI
- 블랙/오프화이트/포인트 컬러 1개 중심
- 큰 여백과 큰 타이포
- 카드형 블록
- 그림자 최소화
- 둥근 코너 12~16px

## 4. 제안 정보구조

### 제안 하단 탭

기존 7개 탭을 4개 탭으로 재구성한다.

1. 오늘
2. 루틴
3. 코치
4. 내 정보

### 탭 재배치 기준

- 홈 + 진행 -> `오늘`
- 운동 + 내 루틴 -> `루틴`
- AI 트레이너 -> `코치`
- 커뮤니티 + 프로필 일부 -> `내 정보`

커뮤니티는 독립 탭에서 빼고, `내 정보` 안의 하위 메뉴 또는 별도 진입 카드로 옮긴다.

이렇게 해야 탭바에서 가장 중요한 기능만 남는다.

## 5. 전체 화면 구조

### 5-1. 오늘

역할:
- 사용자가 앱을 열자마자 "지금 해야 할 행동"을 보여주는 화면

핵심 행동:
- 오늘 운동 시작

섹션 수:
- 4개 이내

와이어프레임:

```text
[상단]
안녕하세요, 하운님
오늘은 하체 루틴 날이에요

[핵심 카드]
오늘의 루틴
스쿼트 · 런지 · 힙쓰러스트
진행률 0%
[운동 시작]

[보조 카드 2개]
최근 기록
이번 주 운동 3회

AI 한 줄 코칭
"오늘은 짧고 정확하게 갑시다"

[하단]
빠른 메뉴
- 루틴 편집
- 기록 보기
```

핵심 포인트:
- 첫 화면은 무조건 "오늘 운동 시작"에 집중
- 그래프보다 행동 버튼이 먼저 보여야 함
- 차트는 요약만 보여주고 상세는 별도 화면으로 이동

### 5-2. 루틴

역할:
- 저장된 루틴 확인
- 커스텀 루틴 만들기
- 운동 리스트 편집

핵심 행동:
- 루틴 생성 또는 실행

구조:

```text
[상단]
루틴
내가 저장한 루틴과 운동 리스트

[Primary CTA]
새 루틴 만들기

[섹션 1]
내 루틴
- 상체 데이
- 러닝 + 코어
- 커뮤니티에서 저장한 루틴

[섹션 2]
운동 라이브러리
- 검색
- 카테고리 필터
- 운동 선택

[섹션 3]
최근 실행한 루틴
```

핵심 포인트:
- `운동`과 `내 루틴`을 합쳐야 구조가 자연스럽다.
- 운동 상세는 루틴을 구성하기 위한 재료여야 한다.
- "음악 플레이리스트 만들기" 같은 편집 감각을 살린다.

### 5-3. 코치

역할:
- AI 트레이너
- 질문/답변
- 페르소나 선택

핵심 행동:
- 질문 보내기

구조:

```text
[상단]
AI 코치
오늘의 질문을 바로 시작해보세요

[섹션 1]
페르소나 스위처
- 다정한 멘토
- 데이터 분석가
- 기가채드

[섹션 2]
추천 질문 카드 3개

[섹션 3]
채팅 영역

[하단 고정]
메시지 입력창 + 보내기
```

핵심 포인트:
- 현재처럼 상단 페르소나 카드가 너무 커서 화면을 먹지 않게 축소
- 가로 pill selector 형태로 단순화
- 채팅 입력창은 항상 명확하게

### 5-4. 내 정보

역할:
- 프로필
- 설정
- 기록/통계 진입
- 커뮤니티/정책 문서 진입

핵심 행동:
- 내 정보 관리

구조:

```text
[상단]
내 정보
프로필 요약

[섹션 1]
내 운동 정보
- 키 / 몸무게 / 목표 / 주 운동 빈도

[섹션 2]
내 기록
- 운동 통계
- 진행률
- PR

[섹션 3]
기타
- 커뮤니티
- 알림 설정
- 개인정보처리방침
- 이용약관
- 로그아웃
```

핵심 포인트:
- 커뮤니티는 핵심 행동이 아니므로 여기로 이동
- 통계는 홈에서 요약, 여기서 상세 확인

## 6. 첫 실행 사용자 흐름

### 목표 경험

사용자는 첫 실행 후 다음 흐름을 자연스럽게 따라야 한다.

```text
로그인
-> 온보딩
-> 오늘 화면
-> 오늘 운동 시작
-> 운동 완료
-> 기록 저장
-> AI 코치 한 줄 피드백
```

### 사용자가 느끼는 경험

- 앱을 켜면 무엇을 해야 할지 바로 안다.
- 선택지가 많지 않아서 덜 부담스럽다.
- 운동 시작까지 탭 1~2번이면 충분하다.
- 기록과 AI 기능이 운동 후 자연스럽게 이어진다.

## 7. 화면별 핵심 UX 원칙

### 공통 레이아웃

- 상단 타이틀은 28~32px
- 서브텍스트는 14~16px
- 카드 간격은 12~16px
- 양옆 padding은 20~24px
- 버튼 높이는 최소 48px 이상

### 카드

- radius 14~16px
- border 1px
- 그림자 최소
- 배경색 대비만으로 계층 표현

### CTA

- 화면당 primary CTA는 1개만
- 나머지는 secondary 또는 텍스트 버튼
- "시작", "저장", "질문 보내기"처럼 동사가 앞에 오는 문구 사용

### 아이콘

- 항상 텍스트와 함께 사용
- 장식보다 의미 전달 우선

### 빈 화면

- 막막하지 않게 다음 행동 제안 포함

예:

```text
아직 저장된 루틴이 없어요
운동 몇 개를 골라 첫 루틴을 만들어보세요
[루틴 만들기]
```

### 에러 화면

- 기술적 문구 대신 행동 중심 문구

예:

```text
루틴을 불러오지 못했어요
잠시 후 다시 시도해주세요
[다시 시도]
```

### 로딩

- 흰 화면 깜빡임 금지
- 기존 배경색 위에 작은 indicator만 노출
- 로딩이 0.3초 이상이면 skeleton 또는 명시적 상태 표시

## 8. 애니메이션 가이드

- 버튼 탭: scale 0.98 / opacity 0.9
- 카드 전환: 0.2~0.25초 fade + translateY 4px
- 탭 전환: 빠른 fade
- 루틴 저장/완료: 짧은 success feedback

과한 패럴랙스, 과한 bounce, 과한 로딩 애니메이션은 피한다.

## 9. 컬러 시스템 제안

메인 컬러는 2~3개만 사용한다.

- Background: near black / off white 중 하나로 통일
- Foreground: high contrast text
- Primary: Heallu 브랜드 포인트 컬러
- Success: 운동 완료/저장용
- Warning: 중급/주의 상태용

추천:

- Primary: 브랜드 레드 또는 주황 계열 1개
- Neutral: 흑백 중심
- Success: 녹색 1개

즉, 색으로 화면을 꾸미기보다 정보 구조로 구분한다.

## 10. Before / After

### Before

- 탭이 많아 첫인상이 복잡함
- 기능이 흩어져 있어 어디로 가야 할지 고민함
- AI, 운동, 루틴, 진행 화면이 서로 비슷한 중요도로 경쟁함
- 긴 설명과 큰 컴포넌트가 많아 핵심 행동이 묻힘

### After

- 첫 화면에서 오늘 해야 할 행동이 바로 보임
- 탭 수가 줄어 학습 비용이 낮아짐
- 루틴 관련 기능이 한 곳으로 모여 더 자연스러움
- AI 화면은 질문 중심으로 단순화됨
- 설정/커뮤니티/정책은 핵심 플로우 밖으로 정리됨

## 11. 우선 구현 순서

1. 하단 탭 7개 -> 4개 재구성
2. 홈 화면을 `오늘` 중심으로 재설계
3. `운동` + `내 루틴` 통합
4. AI 트레이너 상단 구조 축소
5. 프로필에 커뮤니티/정책/설정 이동
6. 빈 화면 / 로딩 / 에러 화면 통일

## 12. 최종 제안 요약

Heallu는 기능이 많은 앱이 아니라, "오늘 운동을 시작하고, 기록하고, AI에게 피드백 받는 앱"으로 느껴져야 한다.

그래서 UI/UX의 핵심은 다음 세 줄로 요약된다.

- 처음 켜면 바로 오늘 해야 할 운동이 보여야 한다.
- 루틴은 한 곳에서 만들고 저장하고 실행할 수 있어야 한다.
- AI는 보조자처럼 자연스럽게 연결되어야지, 별도의 복잡한 제품처럼 느껴지면 안 된다.
